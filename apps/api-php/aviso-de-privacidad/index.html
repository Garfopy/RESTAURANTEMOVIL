Aviso de privacidad de Amare

Este aviso explica el tratamiento de datos personales dentro de la app Amare para cuentas de usuario, pedidos, facturacion, promociones, notificaciones, ubicacion y modo social.

Datos que tratamos

  • Cuenta: nombre, correo, telefono, fecha de nacimiento, foto y autenticacion.
  • Pedidos: carrito, historial, direccion, sucursal, mesa, pagos y solicitudes de factura.
  • Dispositivo: tokens de notificaciones, estado de sesion y datos tecnicos necesarios.
  • Ubicacion: solo cuando el usuario la autoriza para mostrar sucursales o calcular entregas.
  • Modo social: perfil, intereses, fotos, likes, reportes, bloqueos y consentimiento.

Finalidades

Usamos los datos para operar la cuenta, procesar pedidos y pagos, emitir facturas, mejorar soporte, prevenir abuso, enviar notificaciones solicitadas y habilitar funciones sociales cuando el usuario las activa.

Proveedores

Podemos usar proveedores de infraestructura, pagos, mapas, notificaciones, autenticacion y analitica operativa. Solo compartimos datos necesarios para prestar el servicio o cumplir obligaciones legales.

Derechos y eliminacion

El usuario puede actualizar sus datos dentro de la app y eliminar su cuenta en Perfil > Eliminar cuenta. Tambien puede consultar las instrucciones en eliminar cuenta.

Contacto

Para ejercer derechos de privacidad o hacer una solicitud relacionada con datos personales, escribe a soporte@amarerestaurant.club.
